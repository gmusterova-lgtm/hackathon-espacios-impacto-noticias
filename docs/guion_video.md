# Guion breve para enseñar el repositorio en el vídeo

## Qué decir al mostrar GitHub

Este repositorio traduce la propuesta a una estructura de trabajo real. No es solo una idea descrita en un PDF, sino una base organizada para el desarrollo del prototipo.

## Qué enseñar en pantalla

• README con el objetivo y el flujo del sistema
• carpeta `data/demo` con una muestra inicial
• carpeta `src` con la lógica de vinculación y clasificación
• archivo de salida en `outputs/demo_profiles.json`

## Mensaje clave

El valor del repositorio no está en aparentar complejidad, sino en mostrar que la propuesta ya tiene una lógica operativa, trazable y escalable.
